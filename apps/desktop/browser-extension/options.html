Connect Haired

Copy the pairing code from Haired → Settings → Shortcuts. Captured page images go to Haired on this computer, then to your selected AI provider when you request an answer.

Press Haired’s Select tab & answer shortcut, then click your current browser tab or another tab within 30 seconds. The captured page will be answered in Haired.

Only the visible page viewport is captured. Haired’s overlays retain their existing platform-dependent protection; this extension does not hide browser focus changes or guarantee invisibility in recordings.
