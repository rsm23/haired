# Haired v0.1.4 — Browser tab capture and signed macOS installers

This release adds the paired Chrome/Edge companion extension, bundled in both
macOS installers. Select a tab with `Cmd+Option+Shift+T`, then click the current
tab or another tab within 30 seconds. Escape cancels selection silently. The
captured viewport uses the selected provider, default instruction, answer mode,
and encrypted history.

Settings → Shortcuts includes pairing, connection status, **Open extension
folder**, **Copy pairing code**, and **Select tab**. Follow the
[browser tab capture guide](../browser-tab-capture.md) to load and pair the
unpacked extension. There is no Chrome Web Store listing.

Codex and Claude executable discovery now checks common macOS user installation
folders when launched from Finder. Settings labels an unavailable selected
provider **Selected**, and reserves **In use** for a provider that is ready.

## Downloads

- Apple silicon: `Haired-0.1.4-mac-arm64.dmg` and `.zip`.
- Intel: `Haired-0.1.4-mac-x64.dmg` and `.zip`.
- Both app bundles and disk images are Developer ID signed, notarized by Apple,
  and carry stapled notarization tickets.
- `SHA256SUMS.txt` covers the installers, ZIPs, blockmaps, update metadata, and
  `release-verification.json`.
- Windows remains at the existing v0.1.2 preview; this release does not provide
  a new Windows installer or Windows signing certificate.

## Verification and publication

Builds, signing, notarization, checksums, and GitHub Release uploads run locally,
so GitHub Actions billing does not prevent publishing the installers. The
website is built locally and committed to the Pages publishing branch. GitHub
still performs the final Pages deployment; its success must be checked before
claiming that the live site has updated.

Validation includes lint, TypeScript checks, automated tests, production builds,
Developer ID and hardened-runtime checks, Gatekeeper, stapled ticket validation,
and verification of the app, icon, and bundled extension inside each mounted
DMG. The full native meeting, update, and cross-platform browser matrices were
not repeated for this publication. macOS capture protection remains best effort.
