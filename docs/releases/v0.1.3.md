# Haired v0.1.3 — Signed and notarized macOS release

## What changed

Haired v0.1.3 is the first production macOS distribution signed with an Apple
Developer ID Application certificate and accepted by Apple's notarization
service. Both the Apple Silicon and Intel application bundles use the hardened
runtime, carry stapled notarization tickets, and are distributed inside signed,
notarized, and stapled disk images.

The desktop feature set remains compatible with v0.1.2, including Interview
Mode, Fast and Deep reasoning, local and BYOK providers, encrypted local
history, configurable shortcuts, and the screen-region answer workflow. This
version also includes the current product metadata and updater configuration.

## Downloads

- **macOS on Apple silicon:** `Haired-0.1.3-mac-arm64.dmg`
- **macOS on Intel:** `Haired-0.1.3-mac-x64.dmg`
- Portable notarized ZIP archives are included for both processor families.
- Per-architecture SHA-256 manifests and an aggregate `SHA256SUMS.txt` are
  included with the release.

Windows code signing requires a separate Authenticode certificate and is not
provided by an Apple Developer subscription. The existing Windows v0.1.2
preview remains available from the earlier prerelease.

## Release verification

Before publication, the release process:

1. Runs lint, TypeScript checks, the complete Vitest suite, and production builds.
2. Builds Apple Silicon and Intel packages independently.
3. Verifies the Developer ID signature, hardened runtime, team identifier, and bundled icon.
4. Confirms Apple's notarization acceptance and stapled ticket on every app bundle.
5. Notarizes and staples each final DMG, then validates it with Gatekeeper.
6. Mounts each DMG and re-verifies the packaged app.
7. Rejects source maps and common provider-secret patterns.
8. Publishes SHA-256 checksums with the release assets.
