## What changed

Haired v0.1.1 replaces Electron's default executable artwork with Haired's own
warm-orange star mark everywhere users encounter the packaged application. The
macOS application bundle, Finder/Dock icon, DMG, Windows executable, assisted
installer, and uninstaller now share the same identity as the Haired website.

Both Apple silicon and Intel applications are checked again after being placed
inside their DMGs. The release is not published if either packaged macOS icon
or the Windows installer icon differs from the committed Haired artwork.

## Downloads

- **macOS on Apple silicon:** `Haired-0.1.1-mac-arm64.dmg`
- **macOS on Intel:** `Haired-0.1.1-mac-x64.dmg`
- **Windows 10/11 x64:** `Haired-0.1.1-win-x64.exe`
- Portable macOS ZIP archives are included for both processor families.
- Per-platform SPDX SBOMs, checksum manifests, and an aggregate
  `SHA256SUMS.txt` are included with the release.

## Trust and platform notes

- The macOS application is not Developer ID signed or notarized in v0.1.1.
  Gatekeeper may therefore block or warn when opening it for the first time.
- The Windows installer is not Authenticode-signed in v0.1.1. Windows
  SmartScreen may therefore display an unrecognized-app warning on first
  launch.
- Haired's screen-sharing behavior remains **best effort on macOS**. Current
  ScreenCaptureKit paths can ignore AppKit sharing protection, so users must
  verify what meeting participants can see before relying on it.
- Existing settings, provider configuration, shortcuts, and encrypted history
  use the same application identifier and require no migration from v0.1.0.

## Release verification

Before the GitHub prerelease becomes public, the workflow:

1. Runs lint, TypeScript checks, the full Vitest suite, and production builds.
2. Builds the macOS artifacts independently on Intel and Apple silicon targets.
3. Verifies the exact ICNS inside both the unpacked macOS app and mounted DMG.
4. Extracts the Windows installer icon and confirms the Haired orange center
   mark is present instead of Electron's default icon.
5. Rejects source maps and common provider-secret patterns.
6. Generates release-asset checksums and SPDX software bills of materials.

The release remains a prerelease until the native Teams, Zoom, Google Meet,
multi-display, and update matrices in `docs/release-gates.md` are completed for
these exact artifacts.
