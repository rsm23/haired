## What changed

Haired v0.1.2 adds an opt-in Interview Mode for coding answers. When enabled,
the provider receives a provider-neutral instruction to alternate detailed,
interview-ready technical reasoning with the corresponding complete code
sections. The walkthrough covers the problem and constraints, implementation
plan, data structures and control flow, relevant alternatives and trade-offs,
complexity, edge cases, error handling, and validation.

Interview Mode is disabled by default and persists when changed. Enabling it
selects Full reply so its reasoning remains visible; Code only becomes
available again when Interview Mode is disabled.

Answer windows now also distinguish the two capture workflows more clearly:

- **Select & answer** uses the saved instruction internally but does not display
  that instruction as a question above the answer.
- **Select & ask** continues to display the user's typed question.
- Follow-up questions remain visible when the existing answer window is reused.

## Trust and platform notes

- The macOS application is not Developer ID signed or notarized in v0.1.2.
  Gatekeeper may therefore block or warn when opening it for the first time.
- The Windows installer is not Authenticode-signed in v0.1.2. Windows
  SmartScreen may therefore display an unrecognized-app warning on first
  launch.
- Haired's screen-sharing behavior remains **best effort on macOS**. Always
  verify the exact live sharing preview before relying on it.
- Existing settings, provider configuration, shortcuts, and encrypted history
  use the same application identifier and are preserved when upgrading.

## Release verification

Before publication, the release workflow:

1. Runs lint, TypeScript checks, the full Vitest suite, and production builds.
2. Builds Windows x64 and both macOS architecture packages independently.
3. Verifies the committed Haired artwork inside each native package.
4. Rejects source maps and common provider-secret patterns.
5. Produces per-platform and aggregate SHA-256 checksums.
6. Produces SPDX software bills of materials for each platform.
