# Haired releases

This public repository contains signed Haired desktop release assets and update metadata only. Product source code and deployment configuration live in a separate private repository.

- [Privacy](https://haired.example/privacy)
- [Terms](https://haired.example/terms)
- [Help](https://haired.example/help)

Windows capture protection is verified against the supported meeting-share matrix for every release, but it is not DRM or a guarantee against every capture method. macOS protection is best effort.
