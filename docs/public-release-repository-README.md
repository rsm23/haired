# Haired releases

This public repository hosts the generated Haired landing page, desktop release assets, checksums, and update metadata. Product source code and build configuration live in a separate private repository.

- [Website](https://rsm23.github.io/haired-releases/)
- [Privacy](https://rsm23.github.io/haired-releases/#/privacy)
- [Terms](https://rsm23.github.io/haired-releases/#/terms)
- [Help](https://rsm23.github.io/haired-releases/#/help)

Windows capture protection is verified against the supported meeting-share matrix for every release, but it is not DRM or a guarantee against every capture method. macOS protection is best effort.

Preview `v0.1.0` packages are unsigned and may trigger Windows SmartScreen or macOS Gatekeeper warnings. Verify the published SHA-256 checksums before opening an installer.
